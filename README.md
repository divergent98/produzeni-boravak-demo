# Produženi boravak Jež - interaktivni demo

Samostalan HTML demo sa prikazom telefona, roditeljskim i vaspitačkim prikazom i postojećim ekranima aplikacije.

Otvorite `index.html` u pregledaču ili koristite GitHub Pages link repozitorijuma. Fajl sadrži kod i fontove i ne zahtijeva build, instalaciju ili internet vezu nakon preuzimanja.

Podaci su demonstracioni. Promjene važe samo tokom otvorene sesije; osvježavanje vraća početne podatke. Obavještenja su zajednička za oba prikaza; ostali roditeljski podaci prate postojeće odvojene demo primjere. Nema veze sa produkcionom bazom niti stvarnog slanja obavještenja.

## GitHub Pages

U Settings → Pages izaberite Deploy from a branch, granu `main` i folder `/ (root)`, pa sačuvajte.

Za ažuriranje zamijenite `index.html` novom verzijom samostalnog demo fajla. `.nojekyll` zadržava direktno objavljivanje statičkih fajlova.
